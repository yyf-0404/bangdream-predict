## 模型如何预测

模型按档位学习日内活动节奏和平均增长曲线，根据首日分数、活动时长、类型及已公布奖励估计本场的参考走势。随后用本场已观测档线估计四个跨档共享因子和每档两个独立因子。用最近实测分数锚定整段预测，再对有锚点的档位施加名次顺序和时间非降约束。相邻档位可以预测同分。

每次起报先按时间截断原始记录，再插值到半小时网格。新规则以 500、1000、1500、2000 档共同有覆盖的最新网格点作锚，旧规则使用其中实际设立的档位。满 24 小时后开始预测，首日至结算使用同一模型。1500 档在训练集中有 10 场实测，活动前半程的预测不确定性较大。

## 使用发布权重

Python 入口接受毫秒时间戳。结果中 `issued_at_ms` 是起报时刻，`anchor_at_ms` 是当时重点档共同有观测的时刻。只读取 `anchor_mask` 为真的档位，`pred_cutoff` 的最后一行是预测的结算分。

```python
from data import raw
from service.conditional_predictor import ConditionalPredictor

model = ConditionalPredictor()
issued_at = raw.get_start_at(3, 328) + 60 * 3_600_000
result = model.predict_as_of(328, issued_at)
column = result["ranks"].tolist().index(1500)
if result["anchor_mask"][column]:
    print(result["pred_cutoff"][-1, column])
```

HTTP 历史中的 `t0`、`time` 表示计划起报格点及其时间戳，`anchor_t0` 表示该次实际使用的锚点。活动进行中，最新预测的 `t0` 为真实锚点，`prefix_curve` 从锚点后的第一个半小时起算。对尚未取得足够实测历史或当期未设立的档位，接口返回 404。[服务入口](../service/app.py)
